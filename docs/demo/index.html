How should the peers find each other?

Signaling mode
A signaling server brokers one offer and one answer per pair of peers; everyone in a room connects to everyone. Chat never passes through it.
Two peers swap one offer file and one answer file by any channel: chat, email, USB stick. No server at all.

Which signaling server?

The hosted default runs on Vercel; server/ in the repository runs one on Node.js.

Who is this peer?

Comma separated. STUN tells this browser its public address; empty means host candidates only (same machine or LAN).

    Swap PEER.json files

    1. Peer A clicks Create offer and sends the downloaded PEER.json to peer B (chat, email, USB stick, …). Keep this tab open: the offer belongs to it.
    2. Peer B uploads that file. An answer PEER.json downloads automatically; B sends it back to A.
    3. Peer A uploads the answer. The data channel opens and both peers switch to the chat.

    The file holds this peer's SDP and ICE candidates: send it only to the peer you mean.
